## Description
The static filter graph evaluator supports the compositing-critical core but not every SVG Filter Effects primitive. Unsupported nodes currently include feFlood, feMerge, feComponentTransfer, feMorphology, feConvolveMatrix, feDisplacementMap, feTurbulence, image/tile, and lighting primitives. `filterPrimitiveUnits` and separate horizontal/vertical Gaussian deviations also need explicit handling.

## Design
Add primitives in independently tested vertical slices without weakening the graph input/result model from ISS-015. Each slice must define bounds, sampling, color-space assumptions, and transparent-edge behavior before implementation. Do not silently approximate primitives whose browser semantics cannot be represented by the current Image model.

## Acceptance Criteria
- [x] Each newly supported primitive has parsed-SVG pixel tests.

- [x] Two-value `stdDeviation` is supported.
- [x] Unsupported primitives remain explicitly documented until implemented.
