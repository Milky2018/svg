## Description
Introduce 16-bit premultiplied sRGB and linearRGB surfaces, deterministic rounding, bounded surface regions, and the common compositing implementation.

## Design
Keep the new surface types private. Implement source-over, opacity, working-space conversion, isolated-group composition, region origins, and reusable cleared storage before migrating geometry.

## Acceptance Criteria
- [x] Fractional alpha uses round-to-nearest and maps one half to RGBA8 alpha 128.
- [x] Source-over and isolated group opacity pass overlap and transparent-backdrop invariants.
- [x] sRGB and linearRGB conversions are deterministic across all targets.
- [x] Tight surface regions and deterministic buffer reuse are tested.
