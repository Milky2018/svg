## Description
Move clip paths, masks, the parsed filter graph, blend modes, and isolation onto Coverage and bounded premultiplied surface regions.

## Design
Build geometric clip Coverage, render alpha and luminance masks as isolated content, propagate filter primitive regions and color spaces, and reuse cleared filter intermediates by graph liveness.

- [x] General clip paths support units, transforms, use references, nesting, clip rules, and fractional Coverage.
- [x] Alpha and luminance masks support regions, units, nested content, filters, and transparent exterior pixels.
- [x] Every currently parsed filter primitive passes region, input, edge, color-space, and graph-composition tests.
- [x] Every existing blend mode and isolation trigger uses correct premultiplied group composition.
