## Description
Remove mechanical configuration left behind by the repository merge and workspace split. Current examples include empty test import blocks, a package-wide `unused_package` warning suppression, duplicate target ignore patterns, and benchmark support imported directly by the published SVG package.

## Design
Delete empty `import` sections, remove duplicate ignore patterns, and remove the CSS warning suppression before fixing any imports it reveals. Move benchmarks into a dedicated package or another MoonBit-supported layout so production package imports describe runtime code. Do not hand-edit generated interfaces.

## Acceptance Criteria
- [x] No `moon.pkg` contains an empty import block.
- [x] The CSS facade no longer suppresses `unused_package`; real unused imports are removed.
- [x] `.gitignore` contains one unambiguous rule per generated directory.
- [x] Benchmark-only imports and code do not enlarge the normal SVG package contract.
- [x] `moon info`, formatting, and all-target deny-warn checks pass with an intentional diff.
