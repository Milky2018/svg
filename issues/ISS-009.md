## Description
The scene graph and renderer support `Shape::Text` with a font size, but the XML parser treats `<text>` as a group and discards its text content. Consequently inherited and stylesheet font-size behavior cannot be observed through parsed SVG.

## Design
Parse static text content and XML entities into the existing Text shape. Route font-size through computed style inheritance without adding the broader TextStyle model to SVGNode or claiming full SVG text layout support.

## Acceptance Criteria
- [x] Basic `<text x y>content</text>` creates a Text shape.
- [x] Presentation, inline, and embedded stylesheet font-size declarations cascade and inherit.
- [x] CSS-wide keywords and custom properties work for font-size.
- [x] Text rendering and parsing regressions pass on all targets.
- [x] Unsupported nested text layout is documented rather than silently misrepresented.
