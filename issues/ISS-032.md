## Description
Construct SVG Stroke Shapes from continuous curves and render Marker Instances through the ordinary scene pipeline.

## Design
Measure and cut dashes on the original user-space path, construct caps and joins before affine transformation, implement non-scaling-stroke separately in device space, and derive marker placement from SVG path directionality including zero-length vertices.

## Acceptance Criteria
- [ ] Dash arrays, offsets, closed seams, caps, joins, and miter limits pass numeric and raster tests.
- [ ] Non-uniform scale, reflection, rotation, and skew preserve SVG stroke semantics.
- [ ] Non-scaling strokes pass transformed fixtures.
- [ ] Start, mid, and end markers support all orient, units, viewport, overflow, paint-order, and degenerate-path cases.
