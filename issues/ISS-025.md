# ISS-025: Repair viewport, use, clip, and mask transforms

## Description
Local resource rendering is only reliable for narrow fixtures. `<use>` composes x/y placement in the wrong order with its transform, transformed viewports are clipped to an axis-aligned bounding box, clip paths discard all but their first primitive and cannot hit paths, and transformed mask regions are also reduced to an axis-aligned clip.

## Design
Keep local resource lookup unchanged. Correct transform composition, use inverse-affine pixel predicates for viewport and mask-region rectangles, and retain the complete clip-path node tree so paths, multiple children, nested transforms, and clip rules can participate in containment.

## Acceptance Criteria
- [x] `<use>` applies x/y placement before its transform, including referenced-node transforms.
- [x] Rotated and skewed nested viewports clip to the transformed viewport polygon.
- [x] Clip paths combine multiple children and nested transformed groups.
- [x] Path clip geometry honors nonzero and evenodd rules.
- [x] Transformed mask regions clip to their affine rectangle rather than its AABB.
- [x] Existing local viewport, use, clip, and mask fixtures remain green.
- [x] All-target strict checks and tests pass.
