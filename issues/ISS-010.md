## Description
The repository currently duplicates stylesheet tokenization, selector parsing and matching, specificity, cascade ordering, CSS-wide keyword parsing, custom-property processing, and color parsing. `mizchi/css` 0.7.3 already provides these facilities as reusable MoonBit packages.

## Design
Depend on `mizchi/css` and make it the deep CSS module. This repository owns only an SVG adapter: construct CSS elements from SVG XML, add presentation and inline declarations, invoke upstream cascade/computed APIs, and map resulting common/SVG-specific values into SVGNode and resource types. Keep a minimal SVG-property metadata table because upstream intentionally models general CSS rather than SVG paint properties.

## Acceptance Criteria
- [x] `mizchi/css` is pinned as a module dependency and builds on all repository targets.
- [x] Embedded stylesheets, selectors, specificity, media, and cascade use upstream types and functions.
- [x] Inline declarations use upstream parsing/cascade behavior without a second declaration grammar.
- [x] General computed values and inherited custom-property maps use upstream APIs; remaining upstream color/value gaps are tracked separately.
- [x] Redundant local stylesheet/selector/cascade code is removed.
- [x] Existing CSS semantics tests pass on all targets.
