## Description
`mizchi/css` 0.7.3 owns general CSS color parsing, but its computed color parser does not resolve HSL/HSLA and maps unsupported or invalid colors to transparent. SVG needs HSL/HSLA and a result that distinguishes invalid syntax from a valid transparent color before the local compatibility parser can be removed.

## Design
Fix this in `mizchi/css`, not by adding another color grammar or keyword table to this repository. After an upstream release exposes the required behavior, adapt its typed color result to SVG `Color` and delete the local general color parser.

## Acceptance Criteria
- [ ] Upstream parses HSL and HSLA from CSS Color 3.
- [ ] Upstream distinguishes invalid color syntax from valid transparent.
- [ ] `mizchi/css` publishes a release containing the behavior.
- [ ] This repository uses the upstream result for solid colors and removes its general color parser.
