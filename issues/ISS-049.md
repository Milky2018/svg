## Description
Replace the SVG package's handwritten XML tokenization, entity decoding, tag validation, and event traversal with the maintained `Milky2018/xml` streaming parser. The current registry release is 0.2.0 and exposes `Reader::from_string`, a pull-based `read_event` interface, XML element attributes, text and CDATA events, location information, and typed `XmlError` values.

## Design
Feed `Milky2018/xml` events directly into the existing SVG document builder rather than constructing a second generic DOM. Adapt `Start`, `Empty`, `End`, `Text`, and `CData` events while retaining SVG-specific attribute interpretation, resource registration, stylesheet collection, and the parent/sibling stacks required by CSS selectors. Use `Reader::from_string`; do not invoke file parsing or introduce implicit filesystem, network, or external-entity resolution. Pin the selected dependency version through normal MoonBit package management.

## Acceptance Criteria
- [x] `Milky2018/xml` is added as a pinned SVG module dependency using the current supported manifest format.
- [x] SVG XML syntax is consumed through the streaming `Reader::from_string` event interface.
- [x] Handwritten XML scanning, generic entity decoding, and duplicate tag-stack validation are removed.
- [x] SVG-specific parsing, CSS structural context, style text, resource definitions, and document-order behavior remain local to `modules/svg`.
- [x] Regression tests cover namespaces, attributes, entities, text, CDATA, comments, self-closing elements, malformed nesting, and malformed XML.
- [x] String-based SVG parsing performs no implicit file, network, or external-entity access.
- [x] Formatting, generated interfaces, all-target deny-warn checks, and tests pass.
