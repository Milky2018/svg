## Description
Marker positions and orientations are derived separately for line/polyline points and path commands. Degenerate segments, closed subpaths, transformed tangents, markerUnits, and auto-start-reverse therefore need validation after stroke geometry is normalized.

## Design
Retain authored path vertices for marker semantics while sharing tangent calculation and transform handling. Add browser-derived fixtures for start, mid, end, closed, degenerate, and transformed cases.

## Acceptance Criteria
- [x] Line, polyline, polygon, and equivalent path markers agree.
- [x] Degenerate segments use the SVG marker orientation rules.
- [x] auto and auto-start-reverse are covered under transforms.
- [x] markerUnits strokeWidth and userSpaceOnUse are covered.
- [x] All-target strict checks and tests pass.
