# ISS-017: Canonicalize basic geometry and curve coverage

## Description
Equivalent basic SVG geometry currently produces different pixels. Rect rx/ry omission is not paired, circle and equal-radii ellipse use different rasterizers, fully rounded rectangles use a third boundary rule, and polyline has no fill stage.

## Design
Normalize SVG geometry before rasterization and route equivalent curved fills through one pixel-coverage function. Preserve the public scene API and avoid special-case pixel patches.

## Acceptance Criteria
- [x] Omitted rect rx or ry mirrors the specified radius.
- [x] Rounded radii clamp to half of the corresponding side after scaling.
- [x] Equivalent circle, ellipse, and fully rounded rect fills have identical coverage.
- [x] Polygon and closed polyline fills have identical edges.
- [x] All-target strict checks and tests pass.
