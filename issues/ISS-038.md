## Description
Implement the public-boundary decisions from ISS-037. The current SVG package should stop presenting unrelated game, animation, collision, pooling, sprite, or generic image-processing helpers as part of its core contract unless they were explicitly retained.

## Design
Prefer deletion for unowned, unused scope and a separate module only when the repository intentionally commits to maintaining that capability. Internalize renderer-only helpers instead of exposing them. Review `pkg.generated.mbti` as the compatibility diff and avoid compatibility aliases for APIs that the project has deliberately stopped owning unless ISS-037 requires a migration period.

## Acceptance Criteria
- [x] Every API family marked remove, relocate, or internalize in ISS-037 is handled accordingly.
- [x] Renderer and parser behavior remains covered through public black-box tests.
- [x] Tests dedicated only to removed scope are deleted or moved with that scope.
- [x] `moon info` shows only intentional public-interface changes.
- [x] All supported targets pass formatting, deny-warn checks, and tests.
