# ISS-013: Compute font-size from inherited custom properties

## Description
With `mizchi/css` 0.7.3, a child declaration `font-size: var(--size)` computes to the 16px initial value even when `--size: 18px` is present in the inherited custom-property map. The SVG text adapter must not duplicate upstream font-size or var computation to work around this.

## Design
Fix and test custom-property resolution in the upstream pre-seeded font metrics path. Once released, update this dependency and enable the SVG integration regression.

## Acceptance Criteria
- [x] The CSS module computes font-size from a custom property declared on the same element.
- [x] The CSS module computes font-size from an inherited custom property.
- [x] CSS-wide font-size behavior remains correct.
- [x] SVG consumes the fixed local workspace module.
- [x] The SVG text integration test covers `font-size: var(--size)` without local value computation.
