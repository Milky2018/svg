# ISS-051: Document the 0.4.0 rendering API migration

## Metadata
- Type: bug
- Status: closed

- Assignee: codex

- Updated: 2026-07-22

## Description
The historical renderer cutover report still presents the 0.3.1 compatibility
surface as the current public contract, while the 0.4.0 cleanup removed the
document, node, scene, and resolver-specific rendering combinations. The
migration table required by ISS-037 is also missing from current user-facing
documentation.

## Design
Keep the renderer cutover report as historical evidence and mark it as
superseded by the 0.4.0 interface. Add a concise old-to-new API migration table
to the published SVG module guide and the 0.4.0 changelog, with the root README
linking upgrade readers to those sources. Preserve the historical benchmark and
test evidence without rewriting it as current data.

## Acceptance Criteria
- [x] The renderer cutover report clearly identifies its 0.3.1 scope and the superseding 0.4.0 interface.
- [x] The published SVG README maps retained 0.3.x rendering paths to current APIs and identifies removals with no direct replacement.
- [x] The 0.4.0 changelog contains the corresponding migration table.
- [x] Documentation checks and repository diff validation pass.
