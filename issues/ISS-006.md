## Description
mizchi/css owns selector parsing/matching, stylesheet recovery, media rules, and specificity. The SVG parser must provide accurate upstream Element values for attributes and structural relationships without retaining its local selector implementation.

## Design
Build an SVG-to-`mizchi/css/selector.Element` adapter with tag, ID, classes, attributes, parents, and available sibling information. Use the upstream static screen media environment. Clearly exclude interaction state and dynamic DOM invalidation.

## Acceptance Criteria
- [x] No local selector AST, specificity calculator, or stylesheet brace parser remains.
- [x] Attribute selectors work through upstream matching.
- [x] Child, descendant, and available structural selectors receive correct SVG relationships.
- [x] Parser recovery and selector-list handling are covered by upstream behavior plus integration tests.
- [x] Screen-compatible media rules have deterministic behavior with tests.
