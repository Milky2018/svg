# ISS-022: Preserve stroke outlines under general affine transforms

## Description
The shared stroke rasterizer transforms each path centerline into device space and reduces `stroke-width` to one average scale. A general affine transform maps a circular local-space pen into an oriented ellipse, so no single device-space width can represent the correct outline under shear or non-uniform scale. Primitive-to-path lowering fixes shape geometry but intentionally does not hide this remaining stroke-outline defect.

## Design
Construct normalized dash pieces, caps, joins, and miter limits in local user space, then transform the resulting stroke outline through the complete affine matrix before fill rasterization. Preserve the shared stroke behavior established by ISS-018 and keep exact Chromium antialiasing parity outside this issue.

## Acceptance Criteria
- [x] Sheared and non-uniformly scaled strokes transform their complete outline instead of using an average scalar width.
- [x] Dash phase, caps, joins, miter limits, and closed-path handling remain consistent after outline transformation.
- [x] Equivalent primitive and path strokes share the same transformed outline.
- [x] Positive and negative shear produce mirrored stroke geometry within the renderer's documented raster tolerance.
- [x] Existing axis-aligned stroke behavior and public APIs remain unchanged.
- [x] All-target strict checks and tests pass.
