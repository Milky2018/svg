## Description
The SVG parser cannot consume host-provided external stylesheets and does not
expose deterministic media or per-element interaction state to selector
matching.

## Design
Extend render options with an explicit base URI, a text stylesheet resolver,
media environment values, and per-element forced pseudo-class state. Perform
no implicit I/O. Resolve and cache external texts per render with cycle, depth,
and size limits before computing the document-wide cascade.

## Acceptance Criteria
- [x] A host callback supplies stylesheet text for an explicit base URI and href.
- [x] Relative and imported stylesheet references use stable URI resolution.
- [x] Cycles, missing resources, depth limits, and size limits emit diagnostics
  or fail closed without implicit I/O.
- [x] Media state and per-element hover/focus/active state affect the cascade.
- [x] Existing render entry points remain source-compatible.
- [x] Cross-target tests use deterministic in-memory resource bundles.
