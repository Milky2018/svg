# ISS-041: Enforce the full repository gate in CI

## Description
Make GitHub Actions enforce the same validation contract used for local releases. The current workflow watches an obsolete `codex/**` branch pattern, runs only default-target checks and tests, and executes mutating `moon fmt` without failing on a formatting diff.

## Design
Use a branch policy that covers the repository's actual development branches or all relevant pushes. Run formatting in check mode, validate generated interfaces with a clean-tree assertion, and exercise wasm, wasm-gc, JavaScript, and native through the supported all-target commands. Keep the workflow small and avoid adding unrelated release automation.

## Acceptance Criteria
- [x] Push and pull-request triggers match the current repository workflow.
- [x] CI runs `moon fmt --check` rather than a non-enforcing formatter invocation.
- [x] CI runs deny-warn checks and tests on every supported target.
- [x] `moon info` is followed by an effective generated-interface cleanliness check.
- [x] The workflow passes from a clean checkout.
