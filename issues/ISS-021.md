# ISS-021: Preserve affine primitive geometry during rasterization

## Metadata
- Type: bug
- Status: closed
- Priority: 0
- Labels: rendering, transform, geometry, stroke, raster, agent
- Assignee: codex
- Created: 2026-07-20
- Updated: 2026-07-20
- External ref: none

## Description
Transform parsing and matrix application are correct, but primitive rendering does not preserve complete affine geometry. Skewed rectangles are filled as axis-aligned bounding boxes, circles and ellipses discard shear, rounded primitives keep axis-aligned corner geometry, and non-uniformly scaled circles use an average radius. This is an SVG semantic defect independent from deferred Chromium pixel parity.

## Design
Keep the existing semantically valid axis-aligned fast paths, but lower primitives under non-axis-aligned transforms and non-uniformly scaled circles into the same float-space path geometry used by authored paths. Apply the complete affine matrix before final raster quantization, share fill and stroke centerline semantics, and preserve gradient and pattern paint behavior. Transforming the complete stroke outline rather than its centerline is tracked separately by ISS-022. Do not treat residual browser antialiasing differences as part of this issue.

## Acceptance Criteria
- [x] `skewX` and `skewY` render identically to their equivalent `matrix(...)` transforms.
- [x] Skewed rectangles and rounded rectangles match equivalent transformed paths for solid fill and stroke centerlines.
- [x] Skewed circles and ellipses retain the complete affine transform instead of an average-scale approximation.
- [x] Positive and negative shear preserve geometry without filling an axis-aligned bounding box.
- [x] Linear and radial gradient fills remain visible after primitive-to-path lowering.
- [x] Existing semantically valid axis-aligned rendering behavior and public APIs remain unchanged.
- [x] All-target strict checks and tests pass.

## Notes
- 2026-07-20: A 16x16 fixture produced zero differences for `skewX(20)` versus the equivalent matrix and for a transformed path versus a pretransformed path, but 94 differences for a skewed rect versus its equivalent path. An axis-aligned rect/path baseline differed by 16 pixels due to existing edge inclusion rules.

## Close Notes

- 2026-07-20: Lowered rectangles, rounded rectangles, circles, and ellipses to path geometry whenever their fast rasterizers would discard shear, rotation, or non-uniform circle scaling. Added path gradient sampling in local coordinates so lowering does not drop linear or radial paint.
- 2026-07-20: Added positive and negative skew, matrix equivalence, primitive/path, rounded-corner, circle/ellipse, non-uniform scaling, and gradient regressions. `moon check --target all --deny-warn` passed and 324/324 tests passed on wasm, wasm-gc, JavaScript, and native.
