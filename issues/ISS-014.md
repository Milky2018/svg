## Description
The renderer truncates half alpha to 127, overwrites translucent pixels instead of using source-over, ignores opacity on groups, and does not connect the existing blend algorithms to parsed SVG nodes. These defects make opacity, container masks, blending, and isolation observably diverge from browser rendering.

## Design
Use browser-compatible rounding for 8-bit alpha, make Image-backed render targets source-over composite, and route stacking-group effects through one isolated offscreen layer. Preserve callback-only RenderContext behavior, while Image-backed contexts retain the target needed for backdrop-dependent blend modes.

## Acceptance Criteria
- [x] `opacity="0.5"` produces alpha 128.
- [x] Group opacity is applied once after child overlap is rendered.
- [x] Translucent sibling pixels use source-over compositing.
- [x] Container mask and group opacity ordering is covered by pixel tests.
- [x] Programmatic container filter chains process isolated group output.
- [x] Parsed `mix-blend-mode` and `isolation` affect rendering.
- [x] All-target strict checks and tests pass.
