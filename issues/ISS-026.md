# ISS-026: Resolve external SVG resource documents

## Description
External references such as `<use href="icons.svg#item">`, `clip-path="url(resources.svg#clip)"`, and `mask="url(resources.svg#mask)"` cannot be resolved by the current local document registries. The image resolver returns decoded RGBA pixels and cannot supply an SVG resource graph.

## Design
Design a host-provided SVG document resolver with explicit base-URL handling, caching, cycle detection, and resource-tree import semantics. Do not overload the raster image resolver or add implicit filesystem/network access to the core library.

## Acceptance Criteria
- [x] A host can provide external SVG document text or a parsed resource document.
- [x] Relative references resolve against an explicit document base.
- [x] `<use>`, clip paths, masks, gradients, patterns, markers, and filters share cycle-safe external lookup.
- [x] Missing or cyclic resources fail closed without fetching implicitly.
- [x] Cross-target tests cover deterministic in-memory resource bundles.

  diagnoses cycles, missing resources, invalid documents, and configured
  limits. The raster image resolver remains a separate decoded-image seam.
