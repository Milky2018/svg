## Description
Route every preserved high-level rendering entry through the new core, expose typed diagnostics, remove obsolete low-level APIs and raster code, and complete final validation.

## Design
Keep the eight render_svg functions and render_path_commands_to_image source-compatible. Add Render Options and Render Result, retain text through paths or a minimal fallback adapter, preserve full scene and animation behavior, and remove the private coexistence after cutover.

## Acceptance Criteria
- [x] Preserved high-level functions use only the new renderer and retain their signatures.
- [x] Render Result exposes stable typed diagnostics with stage and resource identity.
- [x] PixelSetter, RenderContext, public raster functions, early geometry quantization, and obsolete compatibility branches are removed.
- [x] Formatting, deny-warn checks, generated interfaces, and tests pass for every existing target.
- [x] Final benchmarks satisfy or explain the accepted performance envelope.
- [x] Documentation describes the new public contract and all intentional compatibility changes.
