## Description
Equivalent line and path strokes use different algorithms. Line dashes ignore stroke width and caps, while thick path strokes ignore dasharray. Primitive strokes also approximate outlines independently, producing inconsistent caps and joins.

## Design
Lower line, polyline, polygon, and path strokes into a shared normalized polyline/dash representation, then rasterize the resulting stroke pieces with common cap and join handling. Keep marker placement separate from stroke paint.

## Acceptance Criteria
- [x] Equivalent line and path strokes have identical pixels.
- [x] Dash phase continues across segments and odd-length dash arrays repeat correctly.
- [x] Butt, round, and square caps apply to individual dash pieces.
- [x] Miter limit, bevel, and round joins share one outline path.
- [x] All-target strict checks and tests pass.
