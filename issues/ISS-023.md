# ISS-023: Complete gradient and pattern paint-server semantics

## Description
Gradient and pattern paint servers are parsed but rendered through incompatible shortcuts. Primitive gradient fast paths ignore coordinate units and transforms, radial gradients ignore focal points, and pattern sampling only returns the first solid child hit. As a result, valid paint servers can differ substantially across equivalent shapes and from SVG semantics.

## Design
Use one local-coordinate paint sampler behind shape masks, resolve paint-server coordinates before device rasterization, and render pattern tile content through the normal scene renderer rather than shape hit-testing. Preserve exact Chromium antialiasing parity as the separate deferred ISS-020 concern.

## Acceptance Criteria
- [x] Linear and radial gradients honor object-bounding-box and user-space units plus gradient transforms on equivalent shapes.
- [x] Radial gradients honor focal-point geometry.
- [x] Gradient and pattern reference inheritance resolves local overrides and rejects cycles.
- [x] Patterns honor x/y, units, content units, transforms, viewBox, and preserveAspectRatio.
- [x] Pattern children use normal scene rendering, including transforms, groups, opacity, stroke, gradients, and nested paint.
- [x] Rounded and path geometry clip paint servers to the actual fill shape.
- [x] All-target strict checks and tests pass.
