## Description
The local color parser supports HSL and a small named-color subset, while mizchi/css already provides reusable color parsing with named colors, currentColor, and computed-value context.

## Design
Convert upstream `CssColorValue` and `Color` into the renderer's paint representation. Do not copy an upstream named-color table or color-function parser into this repository. Keep SVG paint-server URL and fallback handling local.

## Acceptance Criteria
- [x] CSS Color 3 named colors, aliases, and `transparent` are supplied by `Milky2018/css`.
- [x] Representative dark/light/gray alias cases are tested.
- [x] Invalid colors are distinguishable from valid black and transparent.
- [x] RGB/RGBA/HSL/HSLA and hex regression tests remain green.
