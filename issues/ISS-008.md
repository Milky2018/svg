## Description
External stylesheets, imported resources, scripting, interaction pseudo-classes, and dynamic DOM restyling require environment and lifecycle interfaces that the synchronous static parser does not currently expose.

## Design
Do not add implicit networking. A future design must decide how callers provide resource bytes, base URLs, media state, interaction state, and invalidation events without coupling the renderer to a platform-specific runtime.

## Acceptance Criteria
- [ ] A separate design defines the resource and dynamic-state seams before implementation.
- [ ] Security, caching, cycles, and deterministic offline behavior are addressed.
- [ ] Public interface changes are reviewed explicitly.
