## Description
External stylesheets, imported resources, interaction pseudo-classes, and
sampled animations require environment and lifecycle interfaces that the
synchronous static parser does not currently expose. Dynamic DOM mutation,
scripting, and an event loop remain outside the renderer's static-snapshot
contract.

## Design
Do not add implicit networking. Callers provide resource text, base URLs, media
state, per-element interaction state, and a sample time through typed render
options. Rendering remains deterministic and synchronous. CSS length
expressions are resolved through an explicit context instead of being reduced
to pixels during token parsing. Dynamic DOM mutation and scripting are
non-goals.

## Acceptance Criteria
- [x] A design defines the resource and static-state seams before implementation.
- [x] CSS and SVG share context-aware length-expression evaluation.
- [x] External stylesheets resolve through a host callback with explicit base URLs.
- [x] Per-element pseudo-class states and a deterministic animation sample time are supported.
- [x] Security, caching, cycles, and deterministic offline behavior are addressed.
- [x] Public interface changes and static-runtime non-goals are documented explicitly.
