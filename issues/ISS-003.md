# ISS-003: Complete CSS-wide and inherited property behavior

## Description
CSS-wide keywords and inheritance currently work only for the core paint whitelist. Recognized SVG properties such as transform, clip-rule, geometry, visibility/overflow where represented, and text styling do not consistently distinguish inherit, initial, unset, revert, and invalid declarations.

## Design
Route every styleable property represented by the scene model through the centralized property seam. Preserve SVG's distinction between inherited and non-inherited properties, and ignore invalid winning declarations according to cascade rules instead of converting them to arbitrary defaults.

## Acceptance Criteria
- [x] `inherit`, `initial`, and `unset` are correct for inherited and non-inherited supported properties.
- [x] `revert` and `revert-layer` have documented behavior for the author-only, layer-free parser.
- [x] Transform, geometry, clip/fill rules, paint properties, markers, and represented text properties have regression tests.
- [x] Invalid declarations are rejected before cascade or become inherited/initial at computed-value time as applicable.
