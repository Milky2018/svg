## Description
SVG geometry currently reduces most authored lengths directly to `Double`.
That prevents correct late resolution of percentages, viewport-relative units,
root-font-relative units, and mixed `calc()` expressions.

## Design
Add a shared structured length expression and an explicit resolution context in
the CSS module. Resolve percentages only when the SVG property supplies its
axis or normalized-diagonal basis. Reuse and replace the separate media-query
length arithmetic where practical. Preserve deterministic font-relative
fallbacks when no host font metrics are available.

## Acceptance Criteria
- [x] Structured values support unitless values, percentages, absolute units,
  `em`, `rem`, `ex`, `ch`, viewport-relative units, and nested `calc()`.
- [x] SVG geometry, nested viewports, use placement, text coordinates, stroke
  widths, and dash lengths resolve through explicit context.
- [x] Invalid dimensional arithmetic and unknown units fail closed.
- [x] Cross-target tests cover mixed units, percentage bases, custom-property
  substitution, and nested viewports.
- [x] Formatting, generated interfaces, deny-warn checks, and tests pass.
