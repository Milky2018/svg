## Description
ISS-016 makes the missing Filter Effects primitive families functional, but it does not claim browser-identical numerical kernels. The renderer still uses its own deterministic sampling for blur, turbulence, lighting, displacement, and convolution, operates in its current image color representation, and does not yet model every primitive subregion or convenience primitive.

## Design
Treat numerical fidelity as a separate standards task from graph coverage. Pin reference fixtures, define the supported `color-interpolation-filters` spaces, model primitive x/y/width/height clipping, and replace each approximate kernel only when its edge, premultiplication, and sampling behavior is covered by differential evidence. Keep exact Chromium antialiasing parity in ISS-020.

## Acceptance Criteria
- [ ] `color-interpolation-filters` selects tested sRGB and linearRGB processing.
- [ ] Gaussian blur, convolution, displacement, morphology, and lighting define premultiplication and transparent-edge behavior against reference fixtures.
- [ ] Turbulence implements the Filter Effects noise and `stitchTiles` semantics with deterministic tests.
- [ ] Primitive x/y/width/height subregions clip intermediate results correctly.
- [ ] `feImage` honors preserveAspectRatio and remaining standard convenience primitives are either implemented or explicitly rejected.
- [ ] Differential fixtures separate semantic mismatches from the raster parity work in ISS-020.
- [ ] All-target strict checks and tests pass.
