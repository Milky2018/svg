## Description
The CSS module parses keyframes and animation longhands, but SVG rendering does
not sample them or apply animation-origin values to computed SVG properties.

## Design
Accept an explicit sample time through the static render environment. Resolve
the active keyframe interval, timing function, direction, iteration, delay,
fill mode, and play state, then interpolate the supported SVG computed values.
Do not add a clock, frame scheduler, mutation loop, scripting, or SMIL runtime.

## Acceptance Criteria
- [x] CSS animations can be sampled deterministically at an explicit time.
- [x] Opacity, paint opacity, colors, transforms, and geometry lengths cover the
  first supported interpolation set; unsupported properties remain discrete.
- [x] Delay, duration, iteration, direction, fill mode, play state, and timing
  functions have regression coverage.
- [x] Animation values participate at the correct cascade origin.
- [x] Cross-target tests and public API documentation pass.
