# ISS-004: Integrate gradient stops with the CSS cascade

## Description
Gradient stops directly parse stop-color and stop-opacity, bypassing stylesheet matching, declaration priority, CSS-wide keywords, custom properties, and currentColor.

## Design
Parse stop elements through the same declaration/cascade machinery as ordinary SVG elements, while producing the existing GradientStop representation and preserving gradient registry behavior.

## Acceptance Criteria
- [x] Presentation, inline, and embedded stylesheet stop declarations share one cascade.
- [x] `!important`, custom properties, CSS-wide keywords, HSL/named colors, and currentColor work for stop-color.
- [x] stop-opacity is clamped after computed-value resolution.
- [x] Linear and radial gradient rendering regressions pass on all targets.
