## Description
Decide whether `Milky2018/css` is a generally consumable CSS library or a static computed-style core maintained specifically for `Milky2018/svg`. The copied facade currently exposes animation and diagnostics APIs in addition to the parser, selector, cascade, media, color, custom-property, and computed-style behavior used by SVG.

## Design
Inventory which CSS packages and public APIs are required by the static SVG pipeline and which exist only because they were present upstream. Define ownership for generic CSS parsing, selectors, cascade, computed values, CSS Color, custom properties, media queries, keyframes, transitions, animation evaluation, and layout-support diagnostics. Preserve standards semantics used by SVG and avoid moving CSS algorithms back into the SVG adapter.

## Decisions

`Milky2018/css` is a generally consumable, semver-versioned static CSS core
maintained in this workspace. SVG is its first integration and acceptance
consumer, not a reason to move generic CSS semantics into `Milky2018/svg`.
The maintained scope covers tokenization, static parsing and recovery,
selectors, cascade, media queries, computed values, custom properties, and CSS
Color. It does not include a browser animation clock/effect runtime, DOM style
invalidation, layout, or a browser-support reporting database.

| Package | Decision | Maintained responsibility |
| --- | --- | --- |
| root facade | keep | Stable entry points for parsing, matching, cascade, computed style, custom properties, and color. |
| `token` | keep | CSS syntax tokenization required by all static parsers. |
| `values` | keep | Shared static CSS value types and parsers. |
| `selector` | keep | Selector parsing, specificity, and matching over the abstract element interface. |
| `media` | keep | Static media-query parsing and evaluation against an explicit environment. |
| `cascade` | keep | Origins, importance, inheritance inputs, rule indexing, and declaration selection. |
| `style` | keep | Computed-style value model used by generic callers and SVG. |
| `parser` | keep | Stylesheets, declarations, inline styles, static at-rules, and recoverable syntax diagnostics. |
| `computed` | keep | CSS-wide keywords, inheritance, custom properties, CSS Color, and computed-value resolution. |
| `animation` | remove | Effect timing, sampling, interpolation tracks, and runtime evaluation are outside the static core. |
| `diagnostics` | remove or internalize | Remove the generic support/layout matrix; retain only parser-owned syntax diagnostics needed for recovery. |

Static `animation-*`, `transition-*`, and `@keyframes` syntax may remain
representable by the parser as CSS source data, but the library will not build
or sample animation effects. Color interpolation needed by static CSS Color
functions belongs to `computed`, not to an animation runtime. Generic grid and
other static grammar support remains in scope even when SVG does not consume it.

Removing the copied runtime and support-report APIs is a breaking change to the
CSS facade. The next independently published CSS release must therefore be a
minor release from `0.7.3` to `0.8.0`; ISS-048 owns release readiness and order.

## Acceptance Criteria
- [x] The intended audience and stability promise of `Milky2018/css` are written down.
- [x] Every CSS subpackage has a keep, remove, internalize, or separate-module decision.
- [x] Static SVG requirements are mapped to the retained CSS APIs.
- [x] Animation, transition, keyframe, and generic layout-diagnostics scope has an explicit disposition.
- [x] Versioning consequences for the CSS module are recorded.
