## Description
Reorganize the retained CSS implementation after scope pruning. The copied core still contains multi-thousand-line computed-style, inline-parser, property-table, and test files that make ownership and safe maintenance difficult.

## Design
Split declarations within their current MoonBit packages by property family or semantic phase without creating filename-based pseudo-modules. Keep tokenizer, selector, cascade, computed-value, color, custom-property, media, and property metadata responsibilities discoverable. Split tests along the same boundaries and preserve black-box coverage for public APIs.
