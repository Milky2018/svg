## Description
Complete the CSS computed-value behavior used by the repository's static SVG parser and renderer. The current implementation handles core paint properties but leaves property metadata scattered, bypasses the cascade for gradient stops and text-related values, implements only part of CSS Color 3, and supports only a small embedded-stylesheet grammar.

## Design
Keep the public parsing and rendering interface stable. Deepen the private style module so cascade, CSS-wide keywords, custom properties, inheritance, and property application share one internal seam. Cover static SVG content that can be resolved from the input document. External resource loading, scripting, interaction state, and dynamic DOM restyling are non-goals for this epic.

## Acceptance Criteria
- [ ] Every child issue is closed with verification evidence.
- [ ] All supported computed properties have explicit initial and inheritance behavior.
- [ ] Inline, presentation, and embedded stylesheet declarations use one cascade.
- [ ] Four-backend tests and strict warning checks pass.
- [ ] Public interface changes are absent or explicitly documented.
