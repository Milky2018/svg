## Description
Review the root, CSS-module, and SVG-module LICENSE, NOTICE, and provenance documentation after the workspace split. The copies are currently identical, while the CSS module contains the derived source and the SVG module consumes it as a workspace and published dependency.

## Design
Keep the Apache-2.0 license and mizchi/css 0.7.3 attribution. Make each NOTICE accurately describe what its distribution contains or depends on, and avoid both accidental attribution removal and misleading claims that every module embeds the copied source. This is a documentation consistency task, not legal advice or a license change.

## Acceptance Criteria
- [x] Root, CSS, and SVG attribution files have an explicit distribution purpose.
- [x] mizchi/css origin, version, URL, and Apache-2.0 attribution remain recorded where required.
- [x] Module README provenance agrees with NOTICE content and the accepted CSS boundary.
- [x] No license text is mechanically rewritten or removed.
