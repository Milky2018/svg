## Description
Reorganize the SVG package after out-of-scope APIs are removed. `types.mbt` and `scene.mbt` are each about 6,000 lines, `parser.mbt` exceeds 4,000 lines, and `svg_wbtest.mbt` mixes thousands of lines of unrelated white-box tests.

## Design
Move declarations within the existing MoonBit package without changing ownership or public signatures. Split by cohesive responsibilities such as core SVG types, geometry, paint servers, resources, filters, images, text, scene mutation, rendering traversal, compositing, and parsing subdomains. Rename the remaining generic `raster.mbt` according to its actual text/bitmap responsibility. Prefer black-box feature tests and keep white-box tests only where private behavior is necessary.

## Acceptance Criteria
- [x] No SVG source or test file remains a catch-all for unrelated subsystems.
- [x] Rendering traversal, effects, resources, parsing, and core data types have discoverable file ownership.
- [x] `raster.mbt` is removed or renamed to match its retained responsibility.
- [x] The generated SVG interface is unchanged except for changes already accepted in ISS-038.
- [x] Formatting, all-target checks, and tests pass.
