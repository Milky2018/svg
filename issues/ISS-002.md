## Description
The computed-style implementation repeats property names, inheritance choices, initial values, and application branches. This makes every property addition a scattered edit and caused incomplete coverage.

## Design
Introduce one private property classification/metadata seam used by declaration collection and computed-value resolution. Keep typed application logic where it improves clarity; do not add a public abstraction or speculative plugin system.

## Acceptance Criteria
- [x] Property classification and inherited/initial behavior have one authoritative definition.
- [x] Existing CSS semantics tests remain unchanged and pass.
- [x] Adding a supported property no longer requires synchronized edits to an unrelated whitelist.
- [x] `moon check --target all --deny-warn` passes.
