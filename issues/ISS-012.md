## Description
`mizchi/css` computes inherited custom-property maps and resolves `var()` for properties known to its computed-style engine. SVG-specific extension properties such as `fill`, `stroke`, marker references, and SVG lengths also need the same resolver, but the upstream generic resolver is private.

## Design
Request or add a public upstream API that resolves a cascaded extension-property value against `ComputeContext`, including nested fallbacks and invalid cycles. This repository should call that API and retain only SVG-specific value parsing.

## Acceptance Criteria
- [ ] Upstream exposes a generic custom-property value resolver or an extension-property compute hook.
- [ ] Nested fallback, missing value, and cycle behavior are covered upstream.
- [ ] `mizchi/css` publishes a release containing the API.
- [ ] This repository deletes its local generic `var()` scanner and uses the upstream API for SVG properties.
